# Cap Rate

The Capitalization Rate (Cap Rate) is a fundamental metric used to estimate the investor's potential return on a real estate property. It is calculated as:

$$\text{Cap Rate} = \frac{\text{Net Operating Income (NOI)}}{\text{Current Market Value (or Purchase Price)}}$$
